# MOTION/3D — Web Motion Design Mastery

An immersive learning site for becoming an expert in web motion design. The page itself is the curriculum: WebGL particle hero, scroll-driven storytelling, spring physics labs, easing curve playground, AI-generated 3D mascot, and award-winning site references.

## Stack
React 19 + TypeScript + Vite + Tailwind CSS + Three.js + GSAP (ScrollTrigger) + Framer Motion + Lenis

## Sections
- 5-Level Learning Path (CSS → GSAP → Physics → Rive → WebGL)
- The 12 Principles of Animation grid
- Easing Curve Lab & Spring Physics Lab (interactive)
- Horizontal scroll field-notes gallery
- Copy-paste code snippets (CSS / GSAP / Framer Motion / Three.js)
- AI-generated chrome Y2K mascot, rendered live (public/models/motion-mascot.glb)
- Tooling comparison, glossary, award showcase, resource links

## Run
```bash
npm install && npm run dev
```
